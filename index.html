Etiqueta meta

Las etiquetas meta aportan información sobre la página. La etiqueta description ayuda a los buscadores a entender el contenido.

Etiqueta col

La etiqueta col define columnas dentro de una tabla usando colgroup.

Etiqueta embed

La etiqueta embed sirve para incrustar archivos como PDF o imágenes SVG dentro de la página.

Etiqueta param

La etiqueta param se usa dentro de object para pasar parámetros, pero está obsoleta y los navegadores modernos la ignoran.

Etiqueta source

La etiqueta source sirve para indicar la fuente de un vídeo o audio dentro de las etiquetas video o audio.

Etiqueta wbr

La etiqueta wbr indica un posible punto de corte dentro de una palabra muy larga.
